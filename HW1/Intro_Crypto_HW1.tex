\question We saw the following definition of {\em negligible} functions in class:

{\bf Definition:} 
{\em A positive function $\mu(n)$ is called {\em negligible} if for any positive polynomial $p(n)$, there exists a constant $n_0$ such that for all $n \geq n_0$ we have $\mu(n) < 1/p(n)$.} 

\begin{parts}
    \part[6] Determine whether each of the following functions is negligible. Justify your answers.
    \begin{enumerate}[label=\roman*.]
        \item $f(n)=2^{-(\log n)(\log\log n)}$
        \begin{solution}
            Para verificar que $f(n)=2^{-(\log n)(\log\log n)}$ es negligible, debemos mostrar que es $O(1/p(n))$ para todo polinomio positivo $p(n)$. Veamoslo con el límite, si es que existe. Si el límite es < $\infty$, entonces pertenece a $O(1/p(n))$, por ende es negligible.
            \[
                \lim_{n \to \infty} \frac{2^{-(\log n)(\log\log n)}}{1/p(n)} = 
                \lim_{n \to \infty} \frac{p(n)}{2^{(\log n)(\log\log n)}} = 
                \lim_{n \to \infty} \frac{p(n)}{n^{\log\log n}}
            \]
            Vemos que, como $p(n)$ es un polinomio positivo, crece como $n^k$ para algún $k > 0$. Como el denominador crece como $n^{\log\log n}$, el exponente no es fijo, y como $n \to \infty$, el exponente tiende a $\infty$, mientras que $k$ es fijo. Por ende, el límite es 0, por ende $f(n)$ es negligible.
        \end{solution}
        \item $f(n)=n^{-1/n}$
        \begin{solution}
            Hacemos lo mismo que en el inciso anterior.
            \[
                \lim_{n \to \infty} \frac{n^{-1/n}}{1/p(n)} = 
                \lim_{n \to \infty} \frac{p(n)}{n^{1/n}} = \infty
            \]
        Vemos que en este caso, el denominador tiende a $1$ y el numerador tiende a $\infty$, luego el límite es $\infty$ y $f(n)$ no es negligible.
        \end{solution}
        \item $f(n)=1/n$ for odd $n$ and $f(n)=2^{-n}$ for even $n$
        \begin{solution}
            En este caso, como la función es partida, tenemos que verificar que ambas son $O(1/p(n))$ para todo polinomio positivo $p(n)$.
            Veamos primero el caso $n$ impar.
            \[
                \lim_{n \to \infty} \frac{1/n}{1/p(n)} = 
                \lim_{n \to \infty} \frac{p(n)}{n} = \infty
            \]
            Luego, como tiende a $\infty$, no es $O(1/p(n))$; luego no es negligible.
        \end{solution}
    \end{enumerate}
    \part[4] We saw that the definition can be restated as follows: 

    {\bf Lemma:} {\em A positive function $\mu(n)$ is {\em negligible} if and only if $\mu(n) \in O(1/p(n))$ for {\em all} positive polynomials $p$.}
    
    Prove the reverse ($\impliedby$) direction of this statement.
    \begin{solution}
        Quiero ver que vale la siguiente implicación: 
        \begin{align*}
            \mu(n) \in O(1/p(n)) \text{ para todo } p(n) \text{ positivo} \implies \mu(n) \text{ es negligible}
        \end{align*}
        La definición de negligible es que, para todo polinomio positivo $p(n)$, existe un $n_0$ tal que para todo $n \geq n_0$ se cumple que $\mu(n) < 1/p(n)$. Esto es muy similar a la definición de $O$, pero sin la constante $c > 0$. 

        \begin{align*}
            \forall p(n) > 0, \exists n_0, c > 0, \forall n \geq n_0, \mu(n) < c \cdot 1/p(n) \\
            \implies \forall q(n) > 0, \exists n_1, \forall n \geq n_1, \mu(n) < 1/q(n).
        \end{align*}
        Luego, como lo de la izquierda vale para cualquier polinomio, lo tomamos para un polinomio particular, con el objetivo de llegar a la expresión de la derecha. Tomamos $n \cdot q(n)$, para un polinomio $q(n)$ positivo cualquiera. Luego,
        \[
            \mu(n) < \frac{c}{n} \cdot \frac{1}{q(n)}
        \]
        Entonces, para llegar a lo de la derecha, queremos mostrar que 
        \[
            \frac{c}{n} \cdot \frac{1}{q(n)} < 1/q(n)
        \]
        Y esto sucede cuando $\frac{c}{n} < 1$, o sea, cuando $c < n$. Luego, para llegar a lo de la derecha, podemos tomar $n_1 = \max(n_0, c)$. Entonces, para todo $n \geq n_1$, se cumple que $\mu(n) < 1/q(n)$, por ende $\mu(n)$ es negligible.
        \qed

    \end{solution}
\end{parts}

\question[10] Assume an attacker knows that a user’s password is either \texttt{abcd} or \texttt{bedg}.
Say the user encrypts his password using the shift cipher, and the attacker sees the resulting ciphertext. Show how the attacker can determine the user’s password, or explain why this is not possible.

\begin{solution}
    En el caso de que la contraseña sea \texttt{abcd}, el cifrado va a ser de cuatro letras consecutivas, ya que se usa el shift cipher, cualquiera sea el $k$ elegido para shiftear. En el caso de que sea \texttt{bedg}, el cifrado no va a tener letras consecutivas, puesto que las letras de esta contraseña no son consecutivas en el abecedario. 
    Luego, el atacante puede distinguir cual es la contraseña simplemente viendo si el cifrado tiene letras consecutivas o no.
\end{solution}

\question[10] We proved in class that if a cipher is {\em perfectly secure/secret}, then it is {\em indistinguishable}. Prove the \textbf{opposite} direction. Begin by stating the perfect security and indistinguishability properties.
\begin{solution}
    Un cipher es perfecto si: \\
    $P(\text{plaintext} = m | \text{ciphertext} = c) = P(\text{plaintext = m})$, para cualquier $m \in \mathcal{M}$.

    Un cipher es indistinguible si: \\
    $\forall m_1, m_2, c, P(Enc(m_1) = c) = P(Enc(m_2) = c)$

    Queremos ver que si es indistinguible, entonces es perfecto. Es decir:
    \begin{align*}
        \forall m_1, m_2 \in \mathcal{M}, \forall c: P(\text{Enc}_K(m_1) = c) = P(\text{Enc}_K(m_2) = c) \\  
        \implies \forall m, c: P(M = m \mid C = c) = P(M = m)
    \end{align*}
    
    Donde $M$ es el plaintext, $C$ es el ciphertext y $\mathcal{M}$ es el espacio de mensajes.

    Sea $m \in \mathcal{M}$ y $c$ un ciphertext con $P(C = c) > 0$. Por Bayes:
    \[
        P(M = m \mid C = c) = \frac{P(C = c \mid M = m) \cdot P(M = m)}{P(C = c)}
    \]
    Luego, basta ver que $P(C = c \mid M = m) = P(C = c)$, de ese modo se cancela con el denominador y queda $P(M = m \mid C = c) = P(M = m)$, que es lo que queremos demostrar. 

    Vemos que $P(C = c \mid M = m) = P(Enc(m) = c)$. Vemos que esta probabilidad es igual para todo $m \in \mathcal{M}$, por indistinguibilidad. Llamamos a este valor $\alpha$, independientemente de qué $m$ tomemos.

    Veamos ahora que $P(C = c) = \alpha$.

    Por probabilidad total:
    \begin{align*}
        P(C = c) = \sum_{m' \in \mathcal{M}} P(C = c \mid M = m') \cdot P(M 
        = m') 
    \end{align*}
    Luego, 
    \begin{align*}
        P(C = c) = \sum_{m' \in \mathcal{M}} P(Enc(m') = c) \cdot P(M = m')
    \end{align*}
    Reemplazamos por $\alpha$:
    \[
        P(C = c) = \alpha \cdot \sum_{m' \in \mathcal{M}} P(M = m') = \alpha \cdot 1 = \alpha
    \]

    Luego, queda demostrado que $P(C = c) = \alpha = P(C = c \mid M = m)$, por ende $P(M = m \mid C = c) = P(M = m)$, que es lo que queríamos demostrar.
    \qed

\end{solution}

\question We look at the different conditions under which the shift and mono-alphabetic substitution ciphers are perfectly secret:
\begin{parts}
    \part[4] Prove that if only a single character is encrypted, then the shift cipher is perfectly secret.
    \begin{solution}
        Buscamos demostrarlo usando la definición de indistinguibilidad. Quiero ver que, para todo $m_1, m_2 \in \mathcal{M}$ (con $|m_1| = |m_2| = 1$), se cumple que:  
        \[
            P(\text{Enc}_k(m_1) = c) = P(\text{Enc}_k(m_2) = c)
        \]
        Veamos para un $m$ arbitrario.
        Luego, por definición del shift cipher:
        \[
            P(m + k \mod |\mathcal{M}| = c) 
        \]
        Reorganizando
        \[
            P(k = (c - m) \mod |\mathcal{M}|) 
        \]
        Vemos que hay una sola clave que hace válida la igualdad. Como la clave se elige aleatoriamente de manera uniforme, la probabilidad de que la clave sea la que hace válida la igualdad es $1$ entre $|\mathcal{K}|$. 
        \[
            P(k = (c - m) \mod |\mathcal{M}|) = \frac{1}{|\mathcal{K}|}
        \]
        Y, como estamos en un shift cipher de un solo caracter, $|\mathcal{K}| = |\mathcal{M}|$. Por ende, 
        \[
            P(k = (c - m) \mod |\mathcal{M}|) = \frac{1}{|\mathcal{M}|}
        \]

        Finalmente, esto vale para todo $m \in \mathcal{M}$. Concluimos entonces que es indistinguible, y por ende es perfectamente secreto.
        \qed

    \end{solution}
    \part[3] Does the perfectly secret conditional probability equation hold for the mono-alphabetic substitution cipher? Elaborate.
    \begin{solution}      
        No, el cipher mono-alfabético de sustitución no es perfecto. Veamoslo con un contraejemplo. 
        
        Tomamos $m_1 = "aa"$, $m_2 = "ba"$ y $c = "cd"$.

        Vemos que la probabilidad de que $c$ sea el ciphertext de $m_1$ es nula, ya que no hay ninguna sustitución mono alfabética que transforme "aa" en "cd" (pues no puede transformar la "a" en la "c" y la "a" en la "d" al mismo tiempo).
        Luego:

        \[
            P(Enc_k(m_1) = c) = 0
        \]

        Vemos que la probabilidad de que $c$ sea el ciphertext de $m_2$ no es nula, ya que a simple vista existe una sustitución mono alfabética que transforme "ba" en "cd" (la "b" se transforma en la "c" y la "a" en la "d").

        No es necesario calcular la probabilidad exacta, ya que basta con saber que es no nula. 

        Luego, no vale la igualdad de probabilidades. Por ende, el cipher mono-alfabético de sustitución no es perfecto.
        \qed

    \end{solution}
    \part[3] What is the largest message space $\cal M$ for which the mono-alphabetic substitution cipher provides perfect secrecy?
    \begin{solution}
        Vemos que solo se cumple para mensajes de longitud $1$, es decir $|\mathcal{M}| = |\Sigma|$. Como vimos anteriormente, con mensajes de longitud $2$ ya no es perfecto. 

        La demostración es muy similar a la de que el shift cipher de un caracter es perfcecto, solamente que la clave no es un shift, si no un mapeo uno a uno entre los caracteres.

        Tomemos $m_1, m_2 \in \mathcal{M}$ y $c$ un ciphertext. Veamos que vale la propiedad de indistinguibilidad, y por ende que es perfecto.

        \[
            P(Enc_k(m_1) = c) = P(Enc_k(m_2) = c)
        \]

        \[
            P(k_{m_1} = c) = P(k_{m_2} = c)
        \]
        
        Donde $k_{m_1}$ es la sustitución de $m_1$ en la clave $k$.

        Vemos que estas probabilidades son iguales para todo $m_1, m_2 \in \mathcal{M}$, con $|m_1| = |m_2| = 1$, dado que la clave es una cualquiera (y es de una distribución uniforme). Por ende, es indistinguible, y por ende es perfecto.
        \qed

    \end{solution}
\end{parts}

\question[10] Suppose you have a message $m$ of length $n$, but you can only generate random keys of length $k$ and $l$ such that $k + \ell = n - 1$. You decide to generate two random keys and combine them with an additional bit. Does the resulting encryption scheme $E_{k_1,k_2}$, defined as follows, provide perfect secrecy?
\begin{center}
      $E_{k_1,k_2}(m) = (k_1\mathbin\Vert 1 \mathbin\Vert k_2) \oplus m$,
\end{center}
where $m \in \{0,1\}^n$, $k_1 \in \{0,1\}^k$, $k_2 \in \{0,1\}^\ell$, and $\Vert$ denotes concatenation. What if instead, the message space is modified to only include messages for which the $(k+1)$th bit is $0$ (i.e., $\mathcal{M}=\big\{m_1\mathbin\Vert0\mathbin\Vert m_2\mathbin\big\vert m_1\in\{0,1\}^k,m_2\in\{0,1\}^\ell\big\}$)?
\begin{solution}
    Para el primer esquema, vemos que no es perfecto. Para esto vamos a ver que no cumple indistinguibilidad, es decir que hay un par de mensajes $m_1, m_2$ y un ciphertext $c$ tal que $P(Enc_{k_1,k_2}(m_1) = c) \neq P(Enc_{k_1,k_2}(m_2) = c)$.
    Elegimos $m_1 = 1^n$, $m_2 = 0^n$ y $c = 1^n$, para cualquier $n$. Tampoco ponemos restricción en $k_1$, $k_2$ ni en sus longitudes. 
    Vemos que:
    \[
        P(Enc_{k_1,k_2}(m_1) = c) = P((k_1 \mathbin\Vert 1 \mathbin\Vert k_2) \oplus 1^n = 1^n) = 0
    \]
    Esto es porque $1 \oplus 1 = 0$. Entonces, cualquiera sea $k$ (la longitud de $k_1$), cuando se aplique el $\oplus$ con $1^n$, el ($k+1$)-ésimo bit será $0$. 

    Vemos ahora que la probabilidad con $m_2$ es distinta de 0.
    \[
        P(Enc_{k_1,k_2}(m_2) = c) = P((k_1 \mathbin\Vert 1 \mathbin\Vert k_2) \oplus 0^n = 1^n) > 0
    \]
    Esto es porque $1 \oplus 0 = 1$. Entonces, cualquiera sea $k$ (la longitud de $k_1$), cuando se aplique el $\oplus$ con $0^n$, el ($k+1$)-ésimo bit será $1$. 
    
    No hace falta calcular la probabilidad exacta, que se puede calcular con combinatorias y las longitudes de $k_1$ y $k_2$, basta con ver que existen claves $k_1$ y $k_2$ tales que se puede generar el ciphertext $c$ con $m_2$ como plaintext. 

    Luego, las probabilidades no son iguales, y por ende no es perfecto.
    \qed \\


    El segundo esquema sí es perfecto. Para verlo, vemos que cumple indistinguibilidad. Veamos la probabilidad para un mensaje $m = m_1 \mathbin\Vert 0 \mathbin\Vert m_2$ genérico, y si logramos llegar a una probabilidad que no dependa de $m_1$ ni $m_2$, entonces es perfecto (ya que podríamos llegar a la misma probabilidad con cualquier otro mensaje del espacio de mensajes)
    \[
        P(Enc_{k_1,k_2}(m_1 \mathbin\Vert 0 \mathbin\Vert m_2) = c) 
    \]
    \[
        P(k_1 \oplus m_1 \mathbin\Vert 1 \mathbin\Vert k_2 \oplus m_2 = c)
    \]
    En el caso de que $c$ tenga un $0$ en el ($k+1$)-ésimo bit, la probabilidad es 0 (lo cual cumple lo que queríamos ver). Asumimos a partir de ahora que $c$ tiene un $1$ en el ($k+1$)-ésimo bit. Es decir, $c = c_1 \mathbin\Vert 1 \mathbin\Vert c_2$.

    \[
        P(k_1 \oplus m_1 = c_1 \land k_2 \oplus m_2 = c_2)
    \]
    Vemos que estas probabilidades son independientes, ya que la clave $k_1$ no afecta a la clave $k_2$ y viceversa.
    \[
        P(k_1 \oplus m_1 = c_1) \cdot P(k_2 \oplus m_2 = c_2)
    \]

    Analicémoslas una por una. La cantidad de claves posibles para $k_1$ es $2^k$. Luego, hay una sola que, dados $m_1, c_1 \in \{0,1\}^k$, haga válida la igualdad. Por ende, la probabilidad es $\frac{1}{2^k}$. Análogamente, $P(k_2 \oplus m_2 = c_2) = \frac{1}{2^\ell}$.

    Luego, la probabilidad total es:
    \[
        P(Enc_{k_1,k_2}(m_1 \mathbin\Vert 0 \mathbin\Vert m_2) = c) = \frac{1}{2^k} \cdot \frac{1}{2^\ell}
    \]
    Que no depende de $m_1$ ni $m_2$, que es lo que queríamos ver. 
    \qed



\end{solution}

\question [10] Assume we require only that an encryption scheme $(\mathsf{Gen}, \mathsf{Enc},\mathsf{Dec})$ with message space $\mathcal{M}$ satisfy the following: For all $m \in \mathcal{M}$, we have $Pr[\mathsf{Dec}_K(\mathsf{Enc}_K(m)) = m] \geq 2^{-t}$. (This probability is taken over the choice of the key as well as any randomness used during encryption.) Show that perfect secrecy can be achieved with $|\mathcal{K}| < |\mathcal{M}|$ when $t\geq 1$. 

\begin{solution}
    Podemos encontrar una solución particular para este esquema que cumple la condición. Notemos que este esquema no cumple con correctitud. 

    Tomamos $\mathcal{K} = \{1\}, Gen = 1, \mathcal{M} = \{0,1\}, t=1$.
    \\ Queremos ver que $P(Dec(Enc(m)) = m) \geq \frac{1}{2}$.
    Luego, si tomamos $Dec(1, m) = m$ y $Enc$ es una función que ignora su entrada y devuelve un $0$ o un $1$ con probabilidad $\frac{1}{2}$, entonces $P(Dec(Enc(m)) = m) = P(Enc(m) = m) = \frac{1}{2}$ 
    Luego, se cumple la condición. 

    Veamos ahora que cumple indistinguibilidad. Para mensajes $m_1, m_2 \in \mathcal{M}$ y un ciphertext $c \in \{0,1\}$ arbitrario, tenemos que:
    \[
        P(Enc(m_1) = c) = P(Enc(m_2) = c) = \frac{1}{2}
    \]
    Luego, cumple indistinguibilidad de manera trivial. Por ende es perfecto.

\end{solution}

\begin{solution}
    Sea el espacio de mensajes $\mathcal{M}$ tal que $|\mathcal{M}| = 2^t$. 
    Sea el espacio de claves trivial $\mathcal{K} = \{k_0\}$, por lo que $|\mathcal{K}| = 1$. 
    Como $t \ge 1$, se garantiza que $|\mathcal{M}| \ge 2$. Por lo tanto, se cumple $|\mathcal{K}| < |\mathcal{M}|$.
    
    Definimos el esquema $(Gen, Enc, Dec)$: $Gen$ siempre devuelve la clave $k_0$; $Enc_K(m)$ ignora el mensaje $m$ y elige un criptograma $c \in \mathcal{M}$ de manera uniforme y aleatoria; $Dec_K(c) = c$ 
    
    Primero, verificamos la condición de probabilidad de descifrado. Para cualquier $m \in \mathcal{M}$:
    $$P(Dec_K(Enc_K(m)) = m) = P(c = m) = \frac{1}{|\mathcal{M}|} = \frac{1}{2^t} = 2^{-t}$$
    
    Finalmente, demostramos que el esquema provee seguridad perfecta mediante indistinguibilidad. Para cualquier par de mensajes $m_1, m_2 \in \mathcal{M}$ y un criptograma arbitrario $c \in \mathcal{M}$:
    $$P(Enc_K(m_1) = c) = \frac{1}{|\mathcal{M}|} = P(Enc_K(m_2) = c)$$
    Esto es porque $Enc$ devuelve un criptograma de manera uniforme y aleatoria, por lo tanto va a devolver el mismo criptograma con la misma probabilidad para cualquier mensaje.
    Luego, se cumple indistinguibilidad. 
    \qed
\end{solution}
